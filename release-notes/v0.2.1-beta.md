A small update to the **MSSB Clone Maker** beta, plus a new tool for opening characters in Blender.

## Download

| System | File |
|---|---|
| Windows | **MSSB-Clone-Maker.exe**: download and double-click, nothing to install. |
| Mac | **MSSB-Clone-Maker-Mac.zip**: unzip, then see [first launch on Mac](https://github.com/Cjericho4/mssb-modding/blob/main/tools/clonemaker/README.md#1-get-the-app). |
| Any (Blender exporter) | **MSSB-Blender-Exporter.zip**: new, see below. |

Already using the Clone Maker? Download the new file and replace the old one. Games you made
earlier keep working.

## New: open characters in Blender

**MSSB-Blender-Exporter.zip** exports any character from your own copy of the game to a file
Blender opens: the textured body, its skeleton, and every batting, running, fielding and pitching
animation. It needs Python 3; the `README.md` inside shows the one command to run and how to pick
an animation in Blender. The exported file contains the game's models, so keep it to yourself.

## Fixes

- **Slot names are readable.** The "Slot it takes over" list no longer cuts names off: recommended
  slots are marked ★ and slots another character already uses are marked ×, with the full
  explanation when you hover.

## Known issues

- On the select screen the big 3D character shows the cloned character in its own colours, not the
  clone's colour.
- Animations marked **"Some bones differ"** can look glitchy in a few moves.
- Some recolours have rough spots, especially on Donkey Kong and Peach. For Peach, tick both **Pink (dress)** and **Dark pink (dress)** to recolour the whole dress.
- Not every character has been played as a clone in Rio yet (Mario, Peach, King Boo and DK have).
- The Mac app isn't signed, so macOS blocks the first launch; the user guide shows how to open it.
- Don't use a patched game for Rio's ranked play.
