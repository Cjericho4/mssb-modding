The first public beta of the **MSSB Clone Maker**: put copies of a character on other characters'
slots in Mario Superstar Baseball (USA), recoloured or wearing textures you painted, with the
character's voice, size and stats. It never changes your original game; it saves a new `.iso`.

## Download

| System | File |
|---|---|
| Windows | **MSSB-Clone-Maker.exe**: download and double-click, nothing to install. |
| Mac | **MSSB-Clone-Maker-Mac.zip**: unzip, then see [first launch on Mac](https://github.com/Cjericho4/mssb-modding/blob/main/tools/clonemaker/README.md#1-get-the-app). |

You need your own Mario Superstar Baseball (USA) `.iso` and Project Rio or Dolphin to play.

## What's in this beta

- **Clones in any colour.** Pick a character, pick the slots it takes over (the extra Toad,
  Shy Guy, Koopa … colours by default, so the select screen stays the same) and a colour for each
  copy. A preview shows every texture before and after.
- **Your own textures.** Export a character's textures as PNG pictures, paint them in any
  program, and give a clone your painted version.
- **The right voice and size.** Clones sound like and are as big as the character they copy.
- **Animations from another character.** Make a clone move like someone else, for example Mario
  with Luigi's animations. Only characters whose skeleton fits are offered.
- **Names and pictures in menus.** The roster, lineup and in-match card show the cloned
  character's name and a picture in the clone's colour, and the announcer says the name
  (can be turned off).
- **Feedback button and update notice.** Report a problem straight from the app, and see a
  **New version** button when a newer release is out.

## Known issues

- Animations marked **"Some bones differ"** can look glitchy in a few moves.
- Some recolours have rough spots, especially on Donkey Kong and Peach.
- The slot list cuts off long names in narrow windows.
- Only Mario-based clones have been fully played in Project Rio so far. Other characters, and
  matches with several clones that each have their own voice, are still being tested.
- The Mac app isn't signed, so macOS blocks the first launch; the user guide shows how to open it.
- Play the clones game offline: Rio's online and ranked modes expect the original game.
