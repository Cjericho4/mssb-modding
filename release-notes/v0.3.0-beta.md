Open any character in Blender, straight from the **MSSB Clone Maker**: its textured body, its
skeleton and all of its animations, in one click.

## Download

| System | File |
|---|---|
| Windows | **MSSB-Clone-Maker.exe**: download and double-click, nothing to install. |
| Mac | **MSSB-Clone-Maker-Mac.zip**: unzip, then see [first launch on Mac](https://github.com/Cjericho4/mssb-modding/blob/main/tools/clonemaker/README.md#1-get-the-app). |
| Any (command line) | **MSSB-Blender-Exporter.zip**: optional, see below. |

Already using the Clone Maker? Download the new file and replace the old one. Games you made
earlier keep working.

## What's new

- **Export a 3D model for Blender.** Click **Export 3D Model** next to **Export Textures**, pick a
  character and save. You get a `.gltf` file with the textured body, the skeleton and every
  batting, running, fielding and pitching animation (untick **All animations** for just the
  swing). In Blender: **File > Import > glTF 2.0**. The
  [user guide](https://github.com/Cjericho4/mssb-modding/blob/main/tools/clonemaker/README.md#open-a-character-in-blender)
  shows how to pick an animation. The file contains the game's models, so keep it to yourself.
- **Models now import upright and whole.** The 0.2.1 Blender exporter zip brought characters in
  upside down, nearly black, and with some parts (Mario's head, for one) far too big and away
  from the body. Now every character stands upright facing the front view, every part is
  attached at its right size, and the textures show under normal lighting. Each game bone is
  also one Blender bone now (before, it was four).
- **Every character exports.** 34 of the 54 characters, among them Luigi, Yoshi, King Boo, the
  Shy Guys and the Magikoopas, couldn't be exported before. Now all of them work, in the app and
  in the zip.
- **No Python needed any more.** The app does what the Blender exporter zip did. The zip is still
  attached for Linux and for its extra options (a single clip, other animation banks, the
  skeleton only); it has the same fix.

## Known issues

- On the select screen the big 3D character shows the cloned character in its own colours, not the
  clone's colour.
- Animations marked **"Some bones differ"** can look glitchy in a few moves.
- Some recolours have rough spots, especially on Donkey Kong and Peach. For Peach, tick both **Pink (dress)** and **Dark pink (dress)** to recolour the whole dress.
- Not every character has been played as a clone in Rio yet (Mario, Peach, King Boo and DK have).
- The Mac app isn't signed, so macOS blocks the first launch; the user guide shows how to open it.
- Don't use a patched game for Rio's ranked play.
