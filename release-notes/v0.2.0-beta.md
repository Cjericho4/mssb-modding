This beta lets one game hold **clones of several characters**: for example two Peach recolours, a
team of King Boos and a DK, all at once.

## Download

| System | File |
|---|---|
| Windows | **MSSB-Clone-Maker.exe**: download and double-click, nothing to install. |
| Mac | **MSSB-Clone-Maker-Mac.zip**: unzip, then see [first launch on Mac](https://github.com/Cjericho4/mssb-modding/blob/main/tools/clonemaker/README.md#1-get-the-app). |

Already using v0.1.0-beta? Download the new file and replace the old one (the app's **New version**
button opens this page). Games you made earlier keep working.

## What's new

- **Clones of several characters in one game.** Click **+ Clone another character** under your
  clones to add a section for another character. Each section has its own character, colours to
  change, clones, animations and textures. Every clone gets the look, voice, size and stats of the
  character it copies, and its chemistry with the other clones follows those characters too.
- **No double-booked slots.** A slot used by one character is greyed out for the others, and a
  character you clone can't also be replaced.
- **Clearer options.** With several characters, the shared options name them all, for example
  "Show each clone as the character it copies (Peach, King Boo)".

Tested in Project Rio with several Peach and King Boo clones in one game. Picking a character
more than once in a team needs a Rio setup that allows it.

## Fixes

- **The "Done!" message no longer ends up off-screen.** With clones of several characters the
  message is long; it now wraps, scrolls if needed and keeps its OK button visible at any window
  size ([#20](https://github.com/Cjericho4/mssb-modding/issues/20)).

## Known issues

- On the select screen, a clone's name box has no colour and the big character picture shows the
  replaced character ([#19](https://github.com/Cjericho4/mssb-modding/issues/19)). A fix is being
  tested.
- Animations marked **"Some bones differ"** can look glitchy in a few moves.
- Some recolours have rough spots, especially on Donkey Kong and Peach.
- The slot list cuts off long names in narrow windows.
- Not every character has been played as a clone in Rio yet (Mario, Peach, King Boo and DK have).
- The Mac app isn't signed, so macOS blocks the first launch; the user guide shows how to open it.
- Play the clones game offline: Rio's online and ranked modes expect the original game.
